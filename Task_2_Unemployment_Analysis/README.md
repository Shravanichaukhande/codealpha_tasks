# Unemployment Analysis with Python

## CodeAlpha Data Science Internship – Task 2

### Objective

The objective of this project is to analyze unemployment data in India and identify trends, regional differences, monthly patterns and the impact of the COVID-19 period.

### Dataset

The dataset contains unemployment information for different regions of India.

Important variables include:

* Estimated Unemployment Rate
* Estimated Employed
* Estimated Labour Participation Rate
* Region
* Area
* Date

### Technologies Used

* Python
* Pandas
* Matplotlib

### Analysis Performed

The project includes:

1. Data loading and cleaning
2. Missing-value handling
3. Overall unemployment rate analysis
4. Regional unemployment comparison
5. Unemployment trend over time
6. Monthly pattern analysis
7. Pre-COVID and COVID-period comparison
8. Data visualization

### Visualizations

The following graphs are generated:

* Average Unemployment Rate by Region
* Unemployment Rate Trend Over Time
* Monthly Unemployment Pattern
* Pre-COVID vs COVID Period

### How to Run

Run:

```bash
python unemployment_analysis.py
```

### Learning Outcome

This project provides practical experience in data cleaning, exploratory data analysis, time-based analysis, visualization and interpretation of unemployment data using Python.
